# 驰声 · 在线直播口播助手

这是原有汽车直播助手的 GitHub Pages 网页版，无需安装 Python 或购买云服务器。

支持多车型讲稿编辑、TXT/Markdown/DOCX 导入、编排与改写、禁用词、播放清单、浏览器语音及背景音乐。讲稿保存在浏览器 localStorage，音乐保存在 IndexedDB，内容不会上传到服务器。

更换电脑可直接打开同一网址使用。各浏览器的数据彼此独立，迁移讲稿时使用顶部“导出备份 / 导入备份”；备份不包含音乐文件。清除网站数据会删除本地保存的内容，请保留外部备份。

语音取决于设备和浏览器。必须点击播放，保持网页开启，并按需通过 OBS 采集当前电脑的声音。

Kokoro、Edge-TTS、第三方付费语音和抖音自动互动需要运行完整版的后端；本网页不包含这些服务。完整源码与 Docker 云端版继续保存在原私有仓库。

推送 main 分支后，GitHub Actions 自动测试并发布网站。文本核心测试：`npm test`。
